# Android求职扩展 第一阶段设计

用户目标：Android原生开发求职；Java/Kotlin为新手。用户已选择“先做第一阶段”，本阶段执行此前说明的登录→今日任务→确认结果，继续使用Kotlin和Compose。

独立工程D:/Codex/MedicationAndroid，不修改毕设后端、鸿蒙端或论文。共用既有REST契约，账号由现有系统提供；只做登录、不扩充注册、建计划或系统通知。

单app模块，data负责Retrofit/JSON及接口语义，ui负责ViewModel/StateFlow与Compose。会话仅在内存，旋转屏幕保留，进程结束重新登录；不保存密码或令牌到明文文件。输入后端根地址，模拟器默认http://10.0.2.2:8080/，真机可填局域网地址。HTTP仅debug允许，release默认禁止。

登录成功后获取今日任务；准确展示药名、剂量、原定时点、状态。只允许WAITING/TRIGGERED且confirmed不为true的任务提交TAKEN/SKIPPED；终态或未知状态不可操作。读取服务端返回action显示最终结果，保留服务端排序及跨日任务，不把稍后当完成，不将未确认称为真实漏服。

同时判断HTTP状态与响应体code。401返回登录、清空任务；退出登录取消请求并阻止旧响应回写。提交锁防重复点击，每次意图生成clientRequestId，网络不确定失败允许复用原ID重试，刷新核对服务端结果。第一版不静默重试写请求。

界面中文、Material3、清晰加载/空态/错误/重试/退出入口。初学者说明包含运行步骤、5个核心文件阅读顺序、三个小练习。以构建、单元/网络测试、lint及可用时模拟器验证为验收，不编造真机结果。
